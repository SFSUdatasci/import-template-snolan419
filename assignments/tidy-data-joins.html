For these new rows, the columns for survey_id, species_id, distance, bird_count, notes, seen, heard, and direction would populate with null values.

# making the birds_obs_subset as specified in the textbook

bird_observations <- bird_observations %>% 
  rename(bird_obs_notes = notes)

bird_obs_subset <- bird_observations %>% 
  full_join(y = taxalist, by = "species_id") %>% 
  full_join(y = sites, by = "site_id") %>% 
  full_join(y = surveys, by = c("site_id", "survey_id")) %>%  
  select(survey_date, common_name, park_name, bird_count, observer)

bird_obs_subset <- bird_obs_subset %>% 
  mutate(observer = if_else(condition = observer == "Josh Burns", 
                            true = "J. Burns", 
                            false = observer))

# making the month column
bird_obs_subset$month = month(bird_obs_subset$survey_date)
bird_obs_subset <- bird_obs_subset %>% 
  mutate(month = as.factor(month)) %>%
  relocate(month, .after = survey_date) %>%
  filter(park_name %in% c("Linda", "Orme", "Palomino", "Sonrisa")) %>%
  group_by(park_name, month)

total_birds = bird_obs_subset %>%
  summarize(total_birds = sum(bird_count)) %>%
  arrange(desc(total_birds))

print(total_birds)

Summary

The resulting data frame outputs the total number of birds observed each month for each park. We can not see that the greatest number of birds was observed in June at Orme, Sonrisa, and Palomino. I wonder if this is due to a biological reason, or if this simply reflects that summer is an ideal time for bird watching. There were some rows with NA values, I would probably go back and remove those. This could be done by filtering them out, or identifying where in the pipeline these rows arose (I suspect it was in the joins).
